# Image directory

The site currently uses remote Unsplash imagery for the demo so it works immediately on GitHub Pages.

For a production deployment, download/licence your preferred agricultural images and place them here with names such as:

- farm-land.jpg
- greenhouse.jpg
- seedlings.jpg
- harvest.jpg
- packhouse.jpg
- delivery.jpg

Then replace the remote image URLs in `index.html` with local paths such as `assets/images/farm-land.jpg`.

Your logos belong in `assets/`:
- `GR.png` — primary logo
- `GRnb.png` — header/alternate logo
